Based on random discord messages I sent:

My personal definition of games being easy/hard is A: how high the skill curve goes + B: how skilled the playerbase is + C: how path-agnostic the path from beginner to master is, given some amount of effort.

there's lots of games which are pretty much open-and-shut put effort in -> get skill out which requires much less forward thinking about how you plan on improving at it

likewise there are a bunch of these games which are like chess, which is very very easy to improve at but you basically need a lifetime tier of hours to get really good at

on the flipside there are games which are really difficult to pathfind high skill for but have pretty low skilled playerbases just due to the game not being too large or optimized

hardest for me is the clear intersection between high skill game / high skill floor community / not very path agnostic

this is still just a cartoon though there's lots of factors which cause little carve out exceptions

games which more intense physical requirements like tac shooters / dance games I guess

but as a first order approximation this is how I think of it, at least

(ycz objection: account for existence of tools and materials to help you improve)
